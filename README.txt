# Birthday Web — Nayesha Salwa Ardilia

Website birthday mobile-first yang dibuat dari foto yang kamu kirim.

## Isi
- `index.html` — halaman utama
- `style.css` — desain/animasi
- `script.js` — interaksi, slideshow, musik, jam, confetti/petal
- `music/birthday-music.mp3` — audio yang diekstrak dari video contoh yang kamu upload
- foto `01.jpg` s/d `11_outro.jpg`

## Cara membuatnya bisa dibuka lewat QR
1. Upload seluruh isi folder ini ke layanan hosting statis, misalnya GitHub Pages, Netlify, atau Vercel.
2. Setelah mendapat URL, misalnya `https://contoh-site.com`, buka `qr.html`.
3. Masukkan URL tersebut dan download QR Code.
4. QR Code itu yang dicetak/dibagikan. Saat discan, orang akan masuk ke website birthday.

Catatan: browser HP biasanya memblokir autoplay audio. Di website ini musik dicoba diputar saat tombol "OPEN GIFT" ditekan, sehingga lebih kompatibel dengan browser mobile.
